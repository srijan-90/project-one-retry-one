CONSISTENCY APP - BEGINNER GUIDE

1. Keep this whole folder together. Do not remove or rename files.

2. QUICK TEST:
   Double-click index.html.
   This lets you preview the app. Some install/offline features may not work this way.

3. RECOMMENDED:
   Install Visual Studio Code.
   Open this consistency folder in VS Code.
   Install the extension called "Live Server".
   Right-click index.html and choose "Open with Live Server".
   Your browser will open the app.

4. IMPORTANT:
   The icons are already inside the icons folder. Keep that folder where it is.

5. YOUR DATA:
   The app stores your habit data in the browser on that device.
   Clearing browser site data can remove the saved data.

6. FREE PHONE VERSION:
   After the app works correctly, publish the folder with a free static host such as GitHub Pages.
   Then open the website on your phone and use the browser's "Add to Home screen" option.

7. If anything goes wrong, take a screenshot of the error and ask for help instead of deleting files.
